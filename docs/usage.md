# 使用指南

## 安装开发版本

1. 按 [开发指南](development.md) 生成 `dist/`。
2. 打开 `chrome://extensions`。
3. 启用 Developer mode。
4. 点击 **Load unpacked**，选择仓库的 `dist/`。
5. 安装完成后会自动打开本地引导页；也可把 Not Brother 固定到工具栏。

开发版更新时，在 `chrome://extensions` 点击“重新加载”后还必须刷新已经打开的 X 标签页。否则标签页里的旧 content script 会被 Chrome 标记为 `Extension context invalidated`；0.4.1 起旧脚本会自动停机，但刷新仍是注入新版本所必需的步骤。

引导页和 Side Panel 会说明扩展读取哪些 X 页面信息、为何读取以及保存在哪里。观察器默认关闭；只有点击“同意并开始”后才会处理页面，随后自动保持运行。之后仍可随时暂停。

工具栏 icon 右下角的状态 badge：酸性黄 `ON` 表示观察中；灰色 `!` 表示已暂停；琥珀色 `!` 表示尚未完成首次设置。

## 界面语言

插件自动支持简体中文、英语和日语，不需要单独设置：Side Panel、完整管理页和工具栏提示跟随 Chrome 界面语言；插入 X 页面中的关系徽标和观察 dock 跟随 X 页面语言。若 X 与 Chrome 使用不同语言，两部分可以各自显示对应语言。其他语言环境回退英语；切换语言后重新打开插件页面或刷新 X。

## 标注与收集

打开 `https://x.com` 后照常浏览。插件只处理当前已经渲染的用户区域，不会自动滚动或打开其他页面。

徽标含义见 [设计文档](design.md)。页面证据不足时不会显示或收集“未知”。“拉黑了你”可来自主动访问资料时的明确提示；在帖子详情/评论线程中，如果该作者的回复、转发、点赞三项全部不可操作且同页另有正常帖子，或其已经完整加载的作者浮窗缺少关注数和粉丝数，也会标记。只有转发不可用或普通“帖子不可用”都不算证据。通过任一路径确认后，本地记录会在以后再次遇到同一 handle 时回标，因此可以在浮窗关闭后继续显示。

我单向关注和 blocked-by 会直接在评论区显示名称同一行显示增强徽标，并给 ID 区域增加琥珀色或红色提示；X 原生 `@handle` 和日期仍保持原位。扩展不会尝试点击这些原生按钮。

如果评论卡片本身没有关注关系提示，可把鼠标停在作者头像或 ID 上，等待 X 作者浮窗完整加载。插件会读取该同 handle 浮窗已经显示的关注/取关控件与“关注了你”指示，用来补全互关、我单向关注或 TA 关注了我；不会自动打开浮窗，也不会点击其中按钮。

刚开始观察且计数为零时，页面 dock 和 Side Panel 会提示悬停作者。这不表示扩展正在后台扫描所有评论；X 只有在浮窗出现后才提供许多关系字段，扩展保持被动读取以避免自动操作页面。

关系证据出现后通常会由 DOM 变化立即触发识别；如果 X 复用了节点或没有发出可捕获的结构变化，可见且运行中的页面最迟约 2 秒会兜底复扫一次。切到后台后暂停这种定期复扫，返回页面或重新获得焦点时立即补查。复扫不会滚动页面，也不会让相同证据每 2 秒重复增加历史。

当前登录账号本人不会进入观察、最近列表或统计。X 页面右下角会显示 Not Brother 观察 dock；点击“查看详情”可直接打开当前标签页的 Side Panel。点击右上角 `×` 会把它收为带运行状态点的 NB 悬浮球，点击悬浮球恢复完整概览；该偏好保存在本机，刷新页面后仍保持。若 Chrome 拒绝程序化打开，dock 会提示改点工具栏 NB icon。

## Side Panel

点击扩展工具栏图标打开侧栏：完成首次同意、查看总数与主要关系计数、查看最近观察、暂停或恢复标注与收集，以及打开完整关系档案库。

- 点击互关、单向关注、关注了你或拉黑了你的分类数字，可筛选下方用户；点击变化提示可查看全部未确认变化；
- 再次点击当前分类可恢复全部最近观察；没有匹配用户时会显示筛选空状态；
- 点击任意用户整行，会由你的点击在新标签页打开该用户的标准 X Profile；扩展不会自动打开或遍历 Profile；
- 未筛选时最多显示最近 8 个用户，筛选后最多显示最近 40 个匹配用户；完整集合仍在关系档案库。

扩展页跟随系统浅色/暗黑偏好；X 页面徽标和 dock 跟随 X 页面实际明暗背景。

## 完整管理页

- 左侧索引按关系筛选；
- 顶部搜索 handle 或显示名称；
- 按最近时间、handle 或观察次数排序；
- 历史按钮展开最近 30 条本地观察；
- 页面徽标、Side Panel 和档案条目会把可归因的变化显示为“回关了你”“取关了你”或“拉黑了你”；无法确认是对方行为的切换仍显示“关系变化”。dock 的“有变化”只显示这些未确认事件的合计数量；
- 对勾按钮确认已经看过关系变化，确认后恢复显示当前基础关系；
- 删除按钮只删除对应本地记录；
- 设置开关控制观察器和页面徽标。
- 页脚的“发送反馈”会在新标签页打开 [GitHub Issues](https://github.com/interjc/chrome-x-not-brother/issues)。

Side Panel 页脚也有同一反馈入口。请不要在议题里粘贴账号密码、Cookie 或含真实关系数据的导出备份。

## 备份与恢复

- JSON：包含 users 与 observations，适合完整备份和合并恢复；
- CSV：包含用户当前摘要，适合表格查看；
- CSV 的机器字段名保持英文，`relationship_label` 按导出时的插件界面语言生成；
- Import：只接受 Not Brother schema v1 JSON，并与现有本地数据合并；
- Clear：二次确认后删除本 Chrome 配置中的全部本地档案。

在清空、换 Chrome 配置或卸载扩展之前先导出 JSON。Chrome 不会自动在配置之间同步 IndexedDB。
