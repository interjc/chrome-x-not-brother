Public HTTPS URLs:

- https://interjc.github.io/chrome-x-not-brother/privacy.html

Store listing copy, the in-extension first-run disclosure, Dashboard Privacy practices, and `terms/privacy.md` must describe the same data categories and purposes. When collection scope changes, update `terms/privacy.md` and the consent version first, then the Store fields.

Paste-ready justifications for each permission in Dashboard **Privacy practices** are in [store-listing.md](../store-listing.md) under Permission justifications. `contextMenus` must be filled in on its own.
