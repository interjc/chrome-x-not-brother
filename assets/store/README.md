# Chrome Web Store 素材

把准备上传的图放在这里，不要用 `output/playwright/` 里的开发截图。拍法和规格见 [docs/deploy.md](../../docs/deploy.md)。

| 建议文件名 | 规格 |
| --- | --- |
| `icon-128.png` | 128×128 PNG，可从 `public/icons/icon-128.png` 复制 |
| `small-promo-440x280.png` | 440×280 PNG，少字 |
| `marquee-1400x560.png` | 1400×560 PNG，可选 |
| `screenshot-01-consent-en.png` | 1280×800，英语同意页 |
| `screenshot-02-x-dock-en.png` | 1280×800，X 页面徽标与 dock |
| `screenshot-03-toolbar-on-en.png` | 1280×800，工具栏 `ON` |
| `screenshot-04-sidepanel-en.png` | 1280×800，Side Panel |
| `screenshot-05-fieldbook-dark-en.png` | 1280×800，暗黑档案库 |

日语、简体中文截图把 `-en` 换成 `-ja`、`-zh`。截图使用虚构或已授权测试账号。
